# Практическая работа: Базовые команды OS Linux

## 1. Работа с каталогами (папками)

*   **pwd** — показывает, в какой папке мы находимся сейчас.
    ```bash
    pwd
    # Вывод: /home/kirill
    ```
*   **cd** — переходит в другую указанную папку.
    ```bash
    cd /etc
    pwd
    # Вывод: /etc
    
    cd ~  # возвращает обратно в домашнюю директорию
    ```
*   **mkdir** — создает новые папки.
    ```bash
    mkdir my_folder          # создал одну папку
    mkdir dir1 dir2 dir3     # создал сразу три папки одной командой
    mkdir -p test/sub/deep   # создал дерево папок (папку внутри папки)
    ```
*   **ls** — показывает список файлов и папок внутри текущего каталога.
    ```bash
    ls
    # Вывод: my_folder dir1 dir2 dir3 test
    
    ls -l   # показывает подробный список (права доступа, размер, дату создания)
    ls -F   # ставит слэш (/) в конце папок, чтобы отличать их от простых файлов
    ```
*   **rmdir** — удаляет пустую папку.
    ```bash
    rmdir dir1
    ```

## 2. Создание и удаление файлов

*   **touch** — быстро создает пустой файл.
    ```bash
    touch notes.txt
    touch file1.txt file2.txt
    ```
*   **cat >** — создает файл и позволяет сразу писать в него текст прямо из консоли.
    ```bash
    cat > hello.txt
    Привет, это проверка команд Linux!
    # Нажимаем Ctrl+D для сохранения и выхода
    ```
*   **rm** — удаляет файлы или папки с файлами.
    ```bash
    rm file1.txt       # просто удалил файл
    rm -i file2.txt    # удаление с предупреждением (спросит подтверждение Y/N)
    rm -r my_folder    # рекурсивно удаляет папку со всем содержимым внутри нее
    ```

## 3. Просмотр содержимого файлов

*   **cat** — выводит весь текст из файла на экран терминала.
    ```bash
    cat hello.txt
    # Вывод: Привет, это проверка команд Linux!
    ```
*   **more** — открывает большие файлы по страницам, чтобы удобно читать (Пробел — листать, q — выйти).
    ```bash
    more /etc/services
    ```

## 4. Копирование, перемещение и переименование

*   **cp** — копирует файлы или целые папки.
    ```bash
    cp hello.txt backup.txt   # скопировал файл в этой же папке под новым именем
    cp hello.txt ./dir2/      # скопировал файл внутрь папки dir2
    cp -r dir2 dir3           # скопировал папку dir2 со всем содержимым внутрь папки dir3
    ```
*   **mv** — переименовывает или переносит объекты.
    ```bash
    mv notes.txt todo.txt     # переименовал файл из notes.txt в todo.txt
    mv todo.txt ./dir3/       # перенес файл todo.txt внутрь папки dir3
    ```

## 5. Выборка и поиск текста внутри файлов (Фильтры)

*   **cut** — вырезает определенные столбцы или символы из текстовых строк.
    ```bash
    # Создадим файл со списком для примера
    cat > users.txt
    1 Ivan   Moscow
    2 Peter  London
    # Нажали Ctrl+D
    
    cut -c 3-7 users.txt
    # Вывод (вырезали символы с 3 по 7):
    # Ivan
    # Peter
    ```
*   **grep** — ищет строки по ключевым словам внутри файлов.
    ```bash
    grep "Moscow" users.txt
    # Вывод: 1 Ivan   Moscow
    
    grep -i "ivan" users.txt   # ищет без учета регистра (большие/маленькие буквы)
    grep -c "London" users.txt # считает количество строк, где нашлось слово (Вывод: 1)
    ```

## 6. Поиск файлов в системе (find)

*   **find** — ищет нужные файлы и папки по заданным условиям.
    ```bash
    find . -name "*.txt"      # нашел все файлы с расширением .txt в текущей папке
    find . -type d            # нашел только каталоги (папки)
    find . -user kirill       # нашел файлы, принадлежащие пользователю kirill
    ```
