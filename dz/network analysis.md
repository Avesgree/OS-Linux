## Задача 1
### Инвентаризация интерфейсов
### Задание: Выведите все сетевые интерфейсы в кратком формате, определите имя основного интерфейса с интернетом, его MAC-адрес и текущий IP.
### Подсказка: ```ip -br a, ip addr show <iface>```.
### Ожидаемый результат: Таблица вида ```enp0s3 UP 192.168.1.50/24, найден MAC```.
### Проверка: ```ip link show <iface> | grep link/ether```.

```bash
ip -br a
ip addr show enp0s3
ip link show enp0s3 | grep link/ether
```

## Задача 2

### Задание: Выведите таблицу маршрутов. Найдите строку ```default via ...```, определите IP шлюза. Проверьте, какой маршрут будет выбран для адреса ```1.1.1.1```.

ip route show
ip route get 1.1.1.1
```

## Задача 3
### Проверка связности по уровням
### Задание: Последовательно проверьте: (1) доступность шлюза, (2) доступность ```8.8.8.8```, (3) резолв домена ```example.com```. Зафиксируйте, на каком шаге что работает.

ping -c 3 192.168.1.1

ping -c 3 example.com

## Задача 7
### Создание dummy-интерфейса
### Задание: Создайте виртуальный dummy-интерфейс ```dummy0```, назначьте ему IP ```10.99.0.1/24```, поднимите его.
### Подсказка:
bash
```sudo ip link add dummy0 type dummy
sudo ip addr add 10.99.0.1/24 dev dummy0
sudo ip link set dummy0 up```
### Ожидаемый результат: ```ip -br a``` показывает ```dummy0 UP 10.99.0.1/24```.
### Проверка: ```ping -c 2 10.99.0.1``` (пинг самого себя через dummy).
### Откат: ```sudo ip link del dummy0```.
